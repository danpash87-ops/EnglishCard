# EnglishCard 🃏

Приложение для изучения английских слов с использованием системы интервального повторения (SRS).

## 🚀 Возможности
- Создание, удаление и категоризация карточек.
- Система SRS: сложные слова (с высоким уровнем) выпадают чаще.
- Режим тренировки с проверкой ответов.
- Работа над ошибками (Hardcore mode).
- Сохранение прогресса в JSON.

## 🛠 Стек
- Python 3.x
- JSON (хранение данных)
- `random.choices` (алгоритм весов)

## 📦 Как запустить
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/danpash87-ops/EnglishCard.git
   
2. Перейдите в папку:
   cd EnglishCard
   
3.Запустите:
   python main.py
